#### Шпаргалка команд по первому уроку

<details>
<summary>Отмена изменений</summary>
✅ До индексации (файл еще не добавлен через git add, только внесли изменения):

```sh
git restore <file>
```

```sh
git config --global user.email
```

✅ Установить имя и ящик:

```sh
git config user.name "ИМЯ"
```

```sh
git config user.email "ЭЛ_ЯЩИК"
```

✅ Настройка окончаний строк:

```sh
git config --global core.autocrlf input (для Unix/Mac)

git config --global core.autocrlf true (для Windows)
```

✅ Показать справку по любой команде Git

```sh
<команда> --help
```

</details>

<details>
<summary>Инициализация репозитория</summary>
✅ Инициализация нового проекта гит

```sh
git init
```

✅ Инициализация проекта с начальным именем кастомной ветки (стандартное имя это master)

```sh
git init -b <имя _ветки>
```

✅ Переименование ветки, находясь в этой же ветке

```sh
git branch -m <новое_имя_ветки>
```

✅ Статус файлов

```sh
git status
```

</details>
<details>
<summary>Фиксация изменений (коммиты)</summary>
✅ Добавить файл в индекс (начать отслеживание)

```sh
git add <имя_файла>
```

✅ Добавить все файлы в индекс

```sh
git add .
```

✅ Зафиксировать изменения с сообщением.

Если опустить флаг -m откроется дефолтный редактор, в зависимоти от того, какой редактор открывается vim nano или иной, необходимо погуглить чтоб выйти из него.

```sh
git commit -m "Сообщение коммита"
```

✅ Объединённые команды для git add . и git commit -m, в том случае если вносились изменения в отслеживаемые файлы.

```sh
git commit -am "Сообщение_коммита"
```

</details>
<details>
<summary>Удаление файлов</summary>
✅ Удалить файл из индекса и рабочей директории.

```sh
git rm <имя_файла>
```

✅ Удалить файл только из индекса, но оставить в рабочей директории.

```sh
git rm --cached <имя_файла>
```

✅ Принудительно удалить файл из индекса и рабочей директории (если он уже был проиндексирован).

```sh
git rm -f <имя_файла>
```

</details>
<details>
<summary>Просмотр истории</summary>

✅ Показать историю коммитов.

```sh
git log
```

✅ Показать информацию об объекте Git

```sh
git show
```

✅ Показать историю в виде графа/дерева.

```sh
git log --graph
```

✅ Открыть графический интерфейс для просмотра истории репозитория.

```sh
gitk
```

</details>
<details>
<summary>Алиасы и Теги</summary>

---

ТЭГИ

---

✅ Создать легковесный тег на текущем коммите.

```sh
git tag <имя_тега>
```

✅ Создать тег с суффиксом.

```sh
git tag <имя_тега>_beta
```

✅ Переключиться на состояние репозитория по тегу.

```sh
git checkout <имя_тега>
```

✅ Показать список всех тегов.

```sh
git tag
```

✅ Создать аннотированный тег с сообщением.

```sh
git tag -a "0.0.2" -m "Тест комментария к тегу"
```

---

АЛИАСЫ

---

✅ Создать алиас (сокращение) для длинной команды. (просто как пример)

```sh
git config alias.show-graph "log --graph --abbrev-commit --pretty=oneline"
```

✅ Удалить алиас

```sh
git config --unset alias.show-graph
```

✅ Показать всю конфигурацию (включая алиасы).

```sh
git config --list
```

</details>
