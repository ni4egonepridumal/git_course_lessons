# В данном репозитории будут размещаться шпаргалки к урокам по курсу

 Каждый урок это отдельная ветка в репозитории:

* Например, для того, чтоб получить шпаргалку первого урока, необходимо:

* Выбрать ветку lesson_1 и файл в ней lesson_1.md

* Для каждого урока выбираем соответсвующую ветку и файл.
